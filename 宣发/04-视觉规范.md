## 一句话风格

**暖紫、米白、一点红；大数字、圆角、留白；像一个小刻度，不像一个健身房。**

关键词：`安静` `克制` `温暖` `触感` `桌面物件`
避免：`科技蓝` `霓虹渐变` `肌肉照` `游戏勋章` `社交排行` `大面积纯黑`

### 使用比例

- 背景 / 白卡：约 85%
- 紫：约 10%
- 红：约 4%
- 绿 / 金：约 1%（只给状态）

> 红色是“动作”和“上涨”；绿色是“下跌”和“已连接”；金色只给“达成”。不要反过来。

## 卡片样式

### 身高大卡

- 背景：`linear-gradient(152deg,#FCFBFF 0%,#F2EBFE 58%,#E8DFFB 100%)`
- 内边距：13px 14px 11px（原型）
- 大数字红色，单位灰紫
- 右上按钮红渐变

### 计数卡

- 白底 `#FFFFFF`

- 左侧标题 + 每组徽标

### 项目卡

- 白底，20px 圆角
- 左侧 42px 紫底图标

- 右侧箭头

### 1×1 方块

- 颜色随组数从灰紫 → 浅红 → 深红（8 档）

- 底部项目名
- 0 组时数字/文字灰紫，1 组以上白色
- 达标后金色 + 白字

## 图标

- 线性图标，1.7px 描边，圆角端点。
- 不用实心彩色图标（除 App 图标）。
- 项目图标：
  - 身高：向上箭头 + 底线
  - 俯卧撑：手臂/地面折线
  - 蹲马步：人形 + 圆
  - 引体向上：单杠 + 双臂

App 图标：红色豆形 + 三条白色刻度 + 右上白色加号。
`brand/daytally-icon-1024.png` 是正式图标；`brand/daytally-icon-alt-1024.png` 是备选圆环版，非当前。

## 布局

### 原型 350px

- 页面左右 padding：16px
- 卡片间距：10px
- 底栏高：60px
- 手机屏：368×784 外框

### 真机 411dp

- 页面左右 padding：16dp（不随 S 放大，贴边更稳）
- 卡片间距：10dp
- 底栏约 70dp
- 五段间隙等距：身高卡后 1 个弹簧 + 4 卡之间 3 个 + 末尾 1 个

### 安全区

- 顶部状态栏 36px，底部手势区留白。
- 关键数字不要贴边；卡片内至少 14px 呼吸。
- 弹窗距屏幕边缘 28dp；键盘上方 16dp。

## 动效

| 动作 | 时长 / 曲线 |
|---|---|
| 卡片按下去 | 180ms，`cubic-bezier(.34,1.56,.64,1)`，scale .982 |
| 按钮按下去 | 160ms，scale .94 |
| 数字变色/跳动 | 320ms，`cubic-bezier(.22,.61,.36,1)` |
| 飘字上浮 | 900～1100ms，ease-out，淡出 |
| 弹窗铺开 | 260ms，spring；遮罩 200ms |
| 页面切换 | 180～220ms，淡入/轻微位移 |

### 触感

- 方块单击：36ms，最大振幅。
- 方块长按：20ms / 200。
- 底栏点击：轻震；双击两次。
- 弹窗错误：一次低音 + 轻震。

## 文案语气

- 短句，口语，像一个人在旁边说。
- 不用“赋能”“闭环”“心智”“颗粒度”等黑话。
- 不喊口号，不制造焦虑。
- 例：
  - “桌面点一下，数字就刻上去。”
  - “今天 6 组 · 昨天 40 组。”
  - “点一下修改。”
  - “不填也能用，数据只留本机。”

避免：

- “坚持就是胜利”
- “自律给你自由”
- “打败 99% 的人”
- “你已连续打卡 365 天”（产品没有这套）

## 摄影 / 视频视觉（给导演）

- 光线：柔和窗光 / 桌面暖光，不用霓虹。
- 场景：木桌、浅色桌垫、手机、手、一杯水；不要健身房大场面。
- 色调：暖紫 + 米白，后期低饱和，红色只留给数字/按钮。
- 镜头：微距手部、45° 俯拍桌面、手机屏幕特写；少用大广角。
- 屏幕内容：后期贴真实 PNG，不要让模型生成 UI。
- 人物：手部为主，不露脸；指甲干净，动作自然。
- 声音：轻触“哒”、数字滚动、一声很轻的确认音；不要宏大配乐。

## Do / Don't

| Do | Don't |
|---|---|
| 让桌面组件占画面中心 | 把 App 主页当唯一主角 |
| 用真实 175.0 / 72 / 33 | 编造 9999 / 100% |
| 红色只给动作/上涨 | 全屏红或全屏紫 |
| 留白 | 塞满功能点 |
| 一次点击一个结果 | 快速剪辑到看不清 |
| 显示“已连接”状态 | 假装云同步 |
| 说明需要局域网 | 说“随时随地云同步” |
