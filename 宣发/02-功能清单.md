### 桌面组件限制

- 4 个 1×1 是独立组件，不是一张大卡切出来的。
- 长按减组依赖桌面进程钩子；没装模块时，长按会弹 MIUI 原生菜单，不会减组。
- 多任务界面里点方块位置可能误加组；已知取舍。
- 组件刷新受 Android 后台限制；同步服务被杀后，桌面仍显示旧值。

## 三、两台手机实时同步（1.2.12）

| 能力 | 说明 | 状态 |
|---|---|---|
| 桌面点击即上传 | `goAsync()` 把广播生命周期挂到 HTTP 回包之后 | 已上线 |
| 另一台实时变 | SSE `event: change`，收到就拉一次快照并刷新组件 | 已上线 |
| 不轮询 | 空闲只有 25 秒 `: ping` 心跳 | 已上线 |
| 事件合并 | 加/减记事件，服务端按事件 id 去重后求和 | 已上线 |
| 换服务器清游标 | 避免旧服务器快照污染新服务器 | 已上线 |
| 开机自启 | `BOOT_COMPLETED` 拉起前台同步服务 | 已上线 |
| 覆盖安装自启 | `MY_PACKAGE_REPLACED` | 已上线 |
| 前台通知 | 低重要性常驻「日刻 · 实时同步」 | 已上线 |
| 只在 Wi‑Fi | 不同步蜂窝数据 | 已上线 |
| 服务端 | Python 标准库 + SQLite + Docker，端口 8787 | 已上线 |

### 同步限制

- 不是系统级推送；MIUI 可能杀服务，需要自启动 / 省电无限制。
- 首次装好或覆盖安装后，可能要打开一次 App 让前台服务启动。
- 锁屏深度休眠可能断连；亮屏/解锁自动重连。
- 服务端需要用户自己部署；公开包不含地址和 Token。
- 不能绕过厂商后台限制，不宣称零耗电。

## 六、明确没有的功能

- 没有 iOS / Web / 桌面端（只有 Android + 桌面组件）。
- 没有账号、云同步、云备份、跨公网访问。
- 没有社区、好友、排行榜、课程、训练计划。
- 没有广告、内购、订阅（截至 1.2.12）。
- 没有 AI 教练、自动识别动作、手表联动。
- 没有健身视频 / 动作库。
