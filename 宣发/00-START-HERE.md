# 60 秒产品 Brief｜日刻 DayTally

## 它是什么

日刻是一个 **Android 桌面优先的每日自我量化工具**。

不是“又一个健身 App”，而是把“今天做了多少”变成桌面上的一个数字：
**点一下方块 = 加一组；抬眼 = 看见今天和周趋势。**

---

## 用户为什么需要它

大多数记录工具的问题是：**记录动作太重。**

- 要解锁、找 App、点进项目、选日期、填数字、保存。
- 一天两天能坚持，忙起来就断。
- 断了两天，用户觉得自己“失败了”，干脆不记了。

日刻把这件事压缩成 **一次点击**：

> 你刚做完一组俯卧撑，手机就在桌上，点一下桌面方块，数字 +1。
> 不用打开 App，不用选日期，不用确认。

---

## 它只做三件事

1. **今天做了多少**：今天页按项目列出累计值，右边大按钮加一组。
2. **这周什么走势**：趋势页 30 天折线，7 天变化、最高、最低，逐日明细。
3. **离目标还有多远**：累计对比目标，进度环和颜色一起走。

其余全部交给桌面：

- 4 个 1×1 方块：俯卧撑 / 蹲马步 / 引体向上 / 自定义。
- 2 张 4×2 大卡：身高卡、计数卡（7 天矩阵 + 项目切换）。
- 单击加一组，长按 0.15 秒减一组（需要 Vector / LSPosed 模块接管）。
- 两台手机实时同数：1.2.12 的 SSE 长连接，约 1 秒。

---

## 一句话差异

**别的 App 让你“去记录”；日刻让记录发生在你已经在的地方——桌面。**

## 产品事实（不要写错）

| 项 | 事实 |
|---|---|
| 产品名 | 日刻 / DayTally |
| 平台 | Android（minSdk 26 / targetSdk 34） |
| 当前版本 | 1.2.12（versionCode 15） |
| 主入口 | 桌面小组件，不是 App 主界面 |
| 数据 | 默认本地 JSON；可选局域网同步，不经过公网 |
| 登录 | 没有账号、没有云账户 |
| 社交 | 没有社区、好友、排行榜、课程、勋章 |
| 广告 | 没有 |
| 长按减组 | 依赖 Vector / LSPosed 模块；不装也能单击加组 |
| 双机同步 | 同一 Wi‑Fi + 自己的树莓派/局域网服务；不是云推送 |
| 已知限制 | MIUI 后台可能杀服务；多任务界面偶发误加组；仅 Android |

## 视频里最值得拍的三件事

1. **一次点击**：手指落在桌面方块上，数字立刻变化。
2. **不打开 App**：镜头从桌面直接切到数字变化，手机屏幕始终没进 App。
3. **另一台手机自己变**：A 手机点，B 手机在旁边亮着，1 秒后数字跟着变。
