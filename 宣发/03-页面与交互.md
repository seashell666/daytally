## 全局

### 屏幕逻辑尺寸

- HTML 原型：宽 **350px**
- 真机参考：小米 11，逻辑宽 **411dp**
- 全局换算：`Ui.S = 411 / 350 = 1.175`
- 规则：尺寸、字号、间距一起放大，保证比例不变。

### 桌面交互

| 操作 | 结果 |
|---|---|
| 点 1×1 方块数字/文字/圆环 | 加一组 |
| 点 1×1 方块边缘留白 | 打开 App（不加组） |
| 长按 1×1 方块 0.15 秒 | 减一组（需模块） |

### 状态

- **未连接同步**：数据只在本机，桌面点击仍可用。
- **已连接同步**：桌面点击后约 1 秒，另一台设备跟着变。
- **同步服务被杀**：桌面仍能点击，数字本地变，另一台不变；打开 App 或 Wi‑Fi 重连恢复。
- **目标达成**：方块/大卡转金色；未达成为紫/红。

## 隐藏设置页

对应：`screens/04-settings.png`、`prototype/phone-settings-connected.png`

### 进入方式

1. 项目页长按标题「项目」**0.7 秒**。
2. 底栏「项目」Tab 长按 **0.7 秒**。
3. 今天页按住左上角日期 **0.7 秒**。

> 不是常规设置入口；这是刻意隐藏的，避免普通用户误入。

### 结构

1. 小字：日刻 · 桌面与模块
2. 标题：设置
3. 桌面长按接管卡
   - 图标：圆角方框 + 手指
   - 标题 + 绿色「已接上」徽标
   - 说明：关掉后桌面方块恢复原生长按，可拖动、可移除
   - 右侧开关
4. 同步服务卡
   - 图标：循环箭头
   - 标题 + 绿色「已连接」
   - 副标题：`192.168.1.50:8787 · 点一下修改`（示意 IP，不是实际地址）
   - 右侧箭头
5. 版本行：日刻 1.2.12 · 预览版
6. 底栏

### 交互

| 操作 | 结果 |
|---|---|
| 点长按接管开关 | 关掉立刻恢复 MIUI 原生菜单；不需要重启 |
| 点同步卡整卡 | 打开同步弹窗 |
| 同步弹窗保存 | 校验 IP/端口/Token；成功回写「已连接」和地址 |
| 点遮罩 / 返回 | 关闭弹窗/回项目页 |

### 同步状态

| 状态 | 颜色 | 含义 |
|---|---|---|
| 未设置 | 红 | 没有填地址 |
| 待连接 | 金 | 填了，还没成功拉过 |
| 已连接 | 绿 | 最近一次同步成功 |
| 连不上 | 红 | 网络/Token/服务端问题 |

## 弹窗与浮层

### 身高弹窗

- 标题「记录身高」
- 输入框 + 厘米单位
- 范围 0～227，可 1 位小数
- 保存 / 取消
- 键盘避让；背景身高卡不被裁

### 项目编辑弹窗

- 每组数量、目标、趋势纵轴上限
- 自动保存；去抖，不叠震动
- 清空按钮：二次确认，说明“会记一个截止时间”

### 同步弹窗

- IP / 主机
- 端口（默认 8787）
- 访问令牌（密码态）
- 保存并连接
- 说明：两台手机填同一个局域网地址和 Token；不填也能用

---

## 交互语气

- 点击反馈要“短、轻、确定”：36ms 震动 + 数字跳一下。
- 不要长震动、不要连续弹窗、不要游戏化礼花。
- 错误只用一次低音 + 一行提示，不羞辱用户。
- 所有自动保存都要有“已经保存”的视觉确认，但不要打断。

## 状态机（给动画/视频用）

```text
桌面待机
  → 手指按下方块
  → 0.93 缩放 + 36ms 震动
  → 数字 +1 组 / 圆环前进 / +12 飘字
  → 组件刷新
  → 若已连接同步：HTTP 上传 → 服务端 revision +1
  → 另一台 SSE 收到 change → 拉快照 → 刷新桌面
  → 1.2 秒内另一台数字跟着变

App 今天页
  → 点右侧加一组
  → 同上的数字/飘字/音效
  → 卡片顶部数值变化
  → 底栏不动

项目页
  → 点卡片
  → 弹窗铺开（从卡片位置放大/淡入）
  → 键盘弹起，弹窗最小上移
  → 自动保存
  → 弹窗收起，卡片数值更新
```
