# AI 使用说明｜怎么让 Claude / ChatGPT / Seedance 2.5 看懂这个包

> 目标：不需要用户再解释，AI 读完这个包就能写方案、分镜、提示词、工作流。

---

## 一、给 AI 的最小上下文

把这一段和 ZIP 一起给它：

```text
这个 ZIP 是「日刻 DayTally」1.2.12 的宣发素材包。

请先读：
1. README.md
2. 00-START-HERE.md
3. 01-产品一页纸.md
4. 02-功能清单.md
5. 03-页面与交互.md
6. 04-视觉规范.md
7. 05-导演手册-视频提示词.md

产品一句话：桌面点一下，数字就刻上去。
它是一个 Android 桌面优先的每日自我量化工具，不是传统健身 App。
核心功能：桌面 1×1 方块点击加组、4×2 大卡看本周、两台手机局域网实时同步、数据默认本地。
当前版本 1.2.12，Android only，无账号、无社区、无广告。

你的任务：基于真实素材，帮我做产品视频的导演、分镜和 Seedance 2.5 提示词。
不要虚构功能；不要让模型生成可读 UI 文字；UI 用包里的 PNG 后期贴。
```

## 二、按任务选 Prompt

### 任务 A｜让 Claude 做“创意导演”

```text
你是产品广告导演。请基于这个包，给「日刻 DayTally」设计 3 支 30 秒产品片方向。

每个方向包含：
- 一句话概念
- 目标受众（投资人 / 普通用户 / 健身人群 / 隐私敏感人群）
- 情绪
- 视觉参考（用包里的哪几张图）
- 分镜节奏（只给 6～8 个节拍，不要写完整镜头表）
- 风险 / 不建议的点

要求：
- 先读懂产品，不要把它写成“健身课程 App”。
- 不要用“云同步”“AI 教练”“多平台”等不存在的功能。
- 不要用健身房大场面。
- 方向要不一样：一个偏社交、一个偏投资人、一个偏产品美学。

输出后停下来等我选，不要直接写 30 个镜头。
```

### 任务 B｜让 ChatGPT 做“分镜表”

```text
你是分镜师。基于我选定的方向，输出一张 30 秒产品片分镜表。

字段：
shot_id | duration | aspect | scene | camera | action | prompt_cn | negative | asset_overlay | text_overlay | sfx | transition

要求：
- 每个镜头 2～5 秒。
- prompt_cn 要能直接给 Seedance 2.5。
- 只生成手 / 手机 / 桌面 / 光，不要求生成 UI 文字。
- asset_overlay 必须从包里的素材选（cards/、prototype/、screens/、promo/）。
- 一次点击只加一组；俯卧撑每组 12，蹲马步每组 11，引体向上每组 12，自定义每组 10。
- 输出 Markdown 表格 + 一段 30 秒粗剪节奏。
```

### 任务 C｜让 ChatGPT 做“Seedance 提示词”

```text
把下面分镜表的每个镜头，改写成 Seedance 2.5 可直接用的提示词。

每条包含：
- 场景（木桌 / 窗光 / 手机 / 手）
- 机位（45° 俯拍 / 微距 / 侧逆光）
- 主体动作（只按一次 / 手离开 / 另一台亮起）
- 镜头运动（固定 / 极慢推 / 轻微后拉）
- 质感（真实实拍 / 浅景深 / 低饱和 / 24fps）
- 负面词（不要文字、数字、UI、Logo、畸形手、多余手机）

输出格式：
shot_id:
prompt_cn:
negative:
duration:
aspect:

分镜表：
[粘贴]
```

### 任务 E｜让 AI 做“发布工作流”

```text
你是内容运营。请基于这个包，给出一个 7 天发布工作流：
- 每天发什么（短视频 / 图文 / 动图）
- 用哪张素材
- 标题 / 封面文案
- 30 秒内能拍完的版本
- 需要后期贴屏的素材
- 发布平台：抖音 / 小红书 / 视频号 / X

约束：不要虚构用户量、收入、融资；不要用“颠覆”“革命”这种词。
```

## 三、AI 必须知道的 10 个事实

1. 产品名：**日刻 / DayTally**。
2. 平台：**Android only**，没有 iOS/Web。
3. 当前版本：**1.2.12 / versionCode 15**。
4. 主入口：**桌面小组件**，不是 App。
5. 桌面组件：4 个 1×1 + 2 张 4×2。
6. 点击加一组；长按 0.15 秒减一组（需 Vector/LSPosed 模块）。
7. 数据默认本地；同步是**局域网**，不是云。
8. 两台手机同步约 **1.2 秒**；不打开 App 也会变。
9. 没有账号、社区、课程、广告、内购。
10. 截图数字是演示数据，不是真实用户数据。

## 四、AI 容易犯的错

| 错误 | 纠正 |
|---|---|
| 写成“健身 App” | 它是“每日自我量化 / 桌面记录工具”，健身只是使用场景之一 |
| 写“云同步” | 是局域网同步，用户自己填 IP / Token |
| 写“AI 教练” | 没有 |
| 写“多平台” | Android only |
| 让 Seedance 生成 UI | 不行；UI 必须后期贴 PNG |
| 数字乱跳 | 一次点击 = 一组；72→84 是 +12 |
| 两台手机同时变 | A 先变，B 约 1.2 秒后变 |
| 用健身房大场面 | 用桌面、手、手机、窗光 |
| 说“零耗电” | 有前台服务，空闲低耗但不是零 |
| 说“绝对不会被杀” | MIUI 可能杀，需要自启动/省电无限制 |

## 五、推荐的输出结构

让 AI 最后交这四样：

1. **创意方向**（3 个，先选）
2. **分镜表**（Markdown 表格，12 列）
3. **Seedance 提示词**（逐镜头，中文）
4. **后期贴屏清单**（PNG + 时间 + 数字动画）

如果它还给了“背景音乐建议 / 字幕 / 封面”，更好，但不要让它写代码。

## 六、给 Seedance 2.5 的“安全生成”策略

### 推荐

- **图生视频**：用 `promo/key-visual-9x16.png` 或干净的桌面/手机照片做首帧。
- 一次只生成一个镜头。
- 屏幕区域保持虚化/纯色/反光。
- 生成 2～3 条，选动作最自然的一条。

### 不推荐

- 文生视频直接要求“手机屏幕上显示日刻 App，数字 175.0”。
- 一个 prompt 生成 30 秒多镜头。
- 让模型生成中文 UI 文案。
- 让模型生成两只手机同时变化。

### 如果必须文生视频

在 prompt 里加：

```text
手机屏幕保持熄灭或纯白反光，不显示任何界面、文字、数字。
```

后期再贴屏。

## 七、一句话总结

**这个包不是“给 AI 一堆图”，而是“给 AI 一套产品事实 + 视觉规则 + 可贴屏素材 + 导演模板”。**
AI 负责创意和镜头，Seedance 负责实拍质感，真实 PNG 负责产品准确性。
