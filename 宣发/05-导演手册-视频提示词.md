# 导演手册｜日刻 1.2.12 产品视频

> 这份手册是给 **Claude / ChatGPT 做导演、写分镜**，再交给 **Seedance 2.5** 生成的。
> 核心原则：**模型只拍“手、手机、桌面、光”，UI 和数字全部后期贴真实素材。**

---

## 一、先定调

### 影片气质

- 安静、温暖、克制。
- 像一个真实用户在早上/晚上做了一组，不是广告片场。
- 画面里只有一件事：**一次点击，带来一个可见的变化。**

### 视觉

- 暖紫 + 米白 + 一点红。
- 木桌、浅色桌垫、手机、手、水杯。
- 柔光，低饱和；红色只给数字/按钮。
- 微距 + 45° 俯拍；不要大广角、不要健身房。

### 声音

- 环境音：房间很轻的底噪、手机放在桌上的轻响。
- 点击：一声很轻的“哒”+ 轻微震动声。
- 数字变化：短促的滚动声，不要“叮咚”游戏音。
- 音乐：极简氛围 / 轻钢琴 / 低鼓点；不要史诗配乐。

### 绝对不要

- 不要生成可读的 UI 文字、数字、按钮。
- 不要虚构“云同步”“AI 教练”“Apple Watch”“多平台”。
- 不要用肌肉男/健身房大场面。
- 不要快速剪辑到看不清点击。
- 不要把 demo 数据说成用户真实数据。

## 二、3 套可直接拍的方案

### 方案 A｜15 秒竖版社交片：**「一次点击」**

**一句话**：从手指落到桌面方块，到数字变化，只用了 1 秒。

| 时间 | 画面 | 声音 / 字幕 |
|---|---|---|
| 0.0–1.5s | 清晨桌面，手机平放，屏幕亮着桌面组件；手入画 | 环境底噪；字幕：`记录一件事，需要多久？` |
| 1.5–3.0s | 微距：拇指按下 1×1 方块；0.93 缩放 | 一声轻“哒”+ 震动 |
| 3.0–5.5s | 特写：数字从 72 → 84（+12）；圆环前进；`+12` 飘字 | 数字滚动；字幕：`1 秒。` |
| 5.5–8.0s | 拉远：手机仍在桌面，没有打开 App；另一台手机在旁边亮起 | 很轻的确认音；字幕：`不用打开 App。` |
| 8.0–11.5s | 另一台手机屏幕：33 → 44（同步）；两只手机同框 | 字幕：`另一台，约 1 秒跟着变。` |
| 11.5–13.5s | App 三页快速但清楚：今天 / 趋势 / 项目 | 字幕：`今天、趋势、项目，都在。` |
| 13.5–15.0s | 品牌收束：App 图标 + 日刻 + 标语 | 字幕：`桌面点一下，数字就刻上去。` |

**适合**：抖音 / 小红书 / 视频号 / X。

---

### 方案 B｜30 秒投资人/产品片：**「把记录缩到一次点击」**

**一句话**：不是又一个健身 App，是把记录从 App 里拿出来，放回桌面。

| 时间 | 画面 | 旁白 / 字幕 |
|---|---|---|
| 0–4s | 桌面上一排健身 App 通知、课程弹窗、打卡页面快速掠过（可用空镜+后期 UI，避免生成文字） | 旁白：`想记一组俯卧撑，要先打开 App、找项目、选日期、填数字。` |
| 4–7s | 手把手机翻面，屏幕朝下；停顿 | 旁白：`大多数记录，死在“太麻烦”。` |
| 7–10s | 手机翻回，桌面组件亮起；手指点一下方块 | 旁白：`日刻把这件事，缩成一次点击。` |
| 10–15s | 特写：数字 +12、圆环、7 天条带；切到今天页 | 旁白：`不用打开 App。今天做了多少，抬眼就知道。` |
| 15–21s | 两台手机并排：A 点，B 不打开 App，1.2 秒后数字跟着变 | 旁白：`一台点一下，另一台约 1 秒跟着变。` |
| 21–25s | 趋势页 30 天折线、项目页累计/目标 | 旁白：`这周什么走势，离目标还有多远，也都在。` |
| 25–28s | 设置页「同步服务」+ 树莓派/路由器空镜（可选） | 旁白：`数据默认只留在手机；要同步，就连自己的局域网。` |
| 28–30s | 品牌收束 | 字幕：`日刻 DayTally · 桌面点一下，数字就刻上去。` |

**适合**：投资人路演插入片、官网首屏、众筹页。

---

### 方案 C｜8 秒循环片：**「数字自己长出来」**

**一句话**：三次点击，三个数字，一个环。没有旁白，适合无声自动播放。

| 时间 | 画面 |
|---|---|
| 0–2s | 微距：拇指按下方块，72 → 84 |
| 2–4s | 同一手指再按，84 → 96；圆环明显前进 |
| 4–6s | 第三次，96 → 108；方块颜色更深一档 |
| 6–8s | 拉远到桌面全景，三条 7 天条带 + 大卡；循环回 0s |

**适合**：官网/GitHub README 动图、信息流循环、Seedance 图生视频。

## 三、Seedance 2.5 镜头提示词

> 用法：每个镜头单独生成 3～5 秒；不要让一个 prompt 包完 30 秒。
> 统一加“全局风格”和“负面词”。UI 后期贴 `cards/*.png`。

### 全局风格（每条都加）

```text
真实手机产品广告实拍，暖紫与米白配色，柔和窗光，浅景深，低饱和，干净的木桌，安静的家居氛围，24fps，产品级质感。画面里不要出现任何可读文字、数字、UI、Logo；手机屏幕保持纯色、模糊或反光，后期贴屏。手部自然，指甲干净，动作缓慢克制。
```

### 负面词（每条都加）

```text
不要生成文字，不要生成数字，不要生成 UI，不要生成 App 界面，不要生成 logo，不要畸形手指，不要多根手指，不要多余手机，不要镜面穿帮，不要闪烁，不要快速运镜，不要健身房，不要肌肉男，不要赛博霓虹，不要夸张特效，不要广告式大笑。
```

### Shot 01｜桌面待机，手入画

```text
清晨的木质桌面，一台深色边框的 Android 手机平放，屏幕亮着但内容虚化，只看到柔和的紫白色光。画面右侧一只干净的手自然入画，拇指靠近手机。45° 俯拍，微距，浅景深，窗光从左上打来，桌面有轻微反光。镜头几乎不动，只有手缓慢进入。3 秒。
```

### Shot 02｜拇指按下 1×1 方块

```text
极近微距，拇指指腹落在一台 Android 手机桌面上的红色圆角小方块上，轻轻按下。手指动作短、稳、只按一次。手机屏幕内容保持虚化/纯色，不要生成任何文字或数字。能看到指尖轻微压紧、皮肤纹理、屏幕微光。侧逆光，浅景深，慢动作 0.5 倍。3 秒。
```

### Shot 03｜数字变化的“结果镜头”

```text
微距特写，手机屏幕的紫白色卡片区域，画面里没有任何可读文字或数字，只保留干净的卡片底色、圆环的一部分、轻微高光。镜头非常慢地向前推 2 厘米，像在看一个数字刚刚变化后的余韵。3 秒。后期在此镜头叠加真实数字滚动和 +12 飘字。
```

### Shot 04｜没有打开 App（手机仍在桌面）

```text
从手机屏幕上方拉远到 45° 俯拍，手机一直平放在木桌上，屏幕停留在桌面组件，没有进入任何 App。一只手离开画面，桌面恢复安静。画面里另一台手机在右后方，屏幕亮起。镜头缓慢后拉，光线柔和。4 秒。
```

### Shot 05｜两台手机同步

```text
两台 Android 手机并排放在木桌上，左手机屏幕亮着，右手机屏幕也亮着但内容虚化。画面只拍手机和桌面，不拍人脸。左手机上方一只手刚点完离开；右手机屏幕在 1 秒后轻微亮起/刷新。镜头固定 45° 俯拍，浅景深，安静。4 秒。后期贴真实同步前后数值。
```

### Shot 06｜App 三页浏览

```text
一只手拿着 Android 手机，拇指在屏幕上轻轻滑动/点击，手机屏幕内容虚化，只能看到紫白色界面块在变化。背景是模糊的桌面和窗光。镜头从手后方 30° 拍，轻微跟随，不快速摇。5 秒。后期贴真实今天/趋势/项目页面。
```

### Shot 07｜品牌收束

```text
干净的米白背景，柔和阴影，画面中央留出放 Logo 的位置，周围是极简的紫白色光晕。没有任何文字或图形，只有光、纸感、留白。镜头非常慢地向前推。3 秒。后期叠加日刻图标和标语。
```

## 四、给 Claude / ChatGPT 的导演工作流

### Step 1｜读

让 AI 按顺序读：

1. `README.md`
2. `00-START-HERE.md`
3. `01-产品一页纸.md`
4. `02-功能清单.md`
5. `03-页面与交互.md`
6. `04-视觉规范.md`
7. 本文件

### Step 2｜选方向

让 AI 先给 **3 个创意方向**，每个包含：

- 一句话概念
- 目标受众
- 时长 / 比例
- 情绪
- 为什么这个方向适合日刻
- 风险

不要直接写 30 个镜头；先拍板方向。

### Step 3｜出分镜表

固定字段（建议用 CSV / Markdown 表格）：

| 字段 | 说明 |
|---|---|
| `shot_id` | S01… |
| `duration` | 秒 |
| `aspect` | 9:16 / 16:9 / 1:1 |
| `scene` | 场景 |
| `camera` | 机位 / 焦段 / 运动 |
| `action` | 画面里发生什么 |
| `prompt_cn` | 给 Seedance 的中文提示词 |
| `negative` | 负面词 |
| `asset_overlay` | 后期贴哪张 PNG |
| `text_overlay` | 字幕 / 旁白 |
| `sfx` | 声音 |
| `transition` | 转场 |

### Step 4｜逐镜头生成

- 每个镜头 3～5 秒，单独生成。
- 先生成“空镜/手部/手机”版本，不要要求模型生成 UI。
- 同一场景的多镜头，保持同一张桌子、同一部手机、同一光线。
- 生成 2～3 条选一条；不要一条用到底。

### Step 5｜后期贴屏

- 用 `cards/*.png` 或 `prototype/phone-*.png` 贴到屏幕区域。
- 数字滚动：0 → 目标值，250～400ms，ease-out。
- `+12` 飘字：上浮 40px，淡出 900ms。
- 圆环：从旧值到新值，跟数字同步。
- 两台手机：A 先变，B 延后 1.2 秒变；不要同时变。

### Step 6｜质检

- [ ] 一次点击只加一组，没有连加。
- [ ] 数字变化符合逻辑（72→84 是 +12）。
- [ ] 没有出现产品没有的功能。
- [ ] 屏幕文字不是 AI 乱码。
- [ ] 两台手机是同一 Wi‑Fi 场景，没有“云”字样。
- [ ] 没有夸张健身/肌肉镜头。
- [ ] 结尾有产品名 + 标语 + 版本。

## 八、镜头连续性检查

| 项 | 规则 |
|---|---|
| 手机 | 同一部深色边框 Android，同一个壁纸/桌面布局 |
| 桌面 | 同一张木桌、同一块桌垫、同一侧窗光 |
| 手 | 同一只右手，指甲干净，不戴夸张饰品 |
| 时间 | 一条片子内保持同一时间段（清晨或傍晚） |
| 数字 | 一次点击只变一组；不要 72 直接跳 100 |
| 同步 | A 先变，B 后变；B 屏幕不要出现 App 主界面 |
| 颜色 | 红色只给动作/上涨；绿色只给下跌/已连接 |
| 字幕 | 不遮挡数字；底部安全区留 15% |
| 品牌 | 结尾才出现完整 Logo；片中不要乱贴标 |
