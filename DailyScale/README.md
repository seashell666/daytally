# 日刻 · daytally

一个用来记录日常次数与身高的小工具：桌面方块点一下就加一组，App 里看趋势，桌面大卡看一周。

## 功能

- **今天页**：项目卡（俯卧撑 / 蹲马步 / 引体向上 / 自定义 / 身高），点卡片加一组、长按退一组，顶部 7 天条带固定「周二 → 周一」。
- **趋势页**：折线图 + 日/周/月切换，左右滑动切换项目。
- **项目页**：新增 / 编辑项目，名称、单位、每组数量、上限组数。
- **桌面组件**
  - 4 个 1×1 方块（俯卧撑 / 蹲马步 / 引体向上 / 自定义），点一下 +1 组，长按退一组。
  - 1 张计数大卡（4×2）：四个项目 tab + 今日数值 + 7 天条带。
  - 1 张身高大卡（4×2）：今日身高 + 「去记录」按钮 + 7 天条带；点主体进趋势，点右上角弹窗直接记身高（浮在桌面，不用进 App）。

## 安装

下载 Release 里的 APK 直接安装。数据存在应用私有目录，卸载会清空。

## 桌面组件长按

Android 的桌面组件（RemoteViews）本身拦不住长按，系统会先接管。所以「长按退一组」做成了一个 **Vector / LSPosed 模块**，和主 App 打在**同一颗 APK** 里。

- 设备装了 Vector（或 LSPosed）并启用本模块 → 桌面上长按日刻方块直接退一组，带音效。
- 没装 / 没启用 → 其余功能完全正常，只是桌面上少了「长按退一组」和对应动画；App 内的长按退组不受影响。

启用方式：在 Vector 管理器里找到「日刻」，勾选作用域 `com.miui.home`（桌面），重启桌面生效。
