# 日刻 · daytally

一个用来记录日常次数与肌肉重量的小工具：桌面方块点一下就加一组，App 里看趋势，桌面大卡看一周。

## 功能

- **今天页**：项目卡（肌肉重量 / 俯卧撑 / 蹲马步 / 引体向上 / 自定义），计数卡点一下加一组、长按退一组，顶部 7 天条带固定「周二 → 周一」。
- **趋势页**：折线图 + 日/周/月切换，左右滑动切换项目；肌肉重量按公斤显示，纵轴固定 47~72。
- **项目页**：新增 / 编辑计数项目，名称、单位、每组数量、上限组数；肌肉重量是记录值，不按计数项目编辑。
- **桌面组件**
  - 4 个 1×1 方块（俯卧撑 / 蹲马步 / 引体向上 / 自定义），点一下 +1 组，长按退一组。
  - 1 张计数大卡（4×2）：四个项目 tab + 今日数值 + 7 天条带。
  - 1 张肌肉重量大卡（4×2）：今日肌肉重量（公斤）+ 「去记录」按钮 + 7 天条带；点主体进趋势，点右上角打开 OKOK 官方称重。
  - 1 张体脂率大卡（4×2）：版式和肌肉重量卡一致，单位 `%`，显示最新体脂率和 7 天条带；右上「去记录」同样打开 OKOK 官方称重。

## 体脂率和肌肉重量怎么记录

1. 在桌面添加「体脂率 · 大卡」或「肌肉重量 · 大卡」。
2. 点卡片右上「去记录」，日刻会打开官方 OKOK 的称重页面。
3. 在 OKOK 里正常登录、连接设备、完成测量；测完回到日刻。
4. 日刻自动读取这次 OKOK 自己生成的体脂率和肌肉重量：体脂率存独立记录，肌肉重量存当天肌肉记录，刷新桌面组件并同步树莓派。
5. 只有没收到 OKOK 结果时，才显示“再试 OKOK / 保存手动记录”兜底；手动记录会明确标记，不冒充 OKOK。

旧版的“身高”历史仍保留在本机 JSON 里做兼容，但不再显示、不再写入新值，也不会以“公斤”形式出现。

## 安装

下载 Release 里的 APK 直接安装。数据存在应用私有目录，卸载会清空。

## 桌面组件长按

Android 的桌面组件（RemoteViews）本身拦不住长按，系统会先接管。所以「长按退一组」做成了一个 **Vector / LSPosed 模块**，和主 App 打在**同一颗 APK** 里。

- 设备装了 Vector（或 LSPosed）并启用本模块 → 桌面上长按日刻方块直接退一组，带音效。
- 没装 / 没启用 → 其余功能完全正常，只是桌面上少了「长按退一组」和对应动画；App 内的长按退组不受影响。

启用方式：在 Vector 管理器里找到「日刻」，勾选作用域 `com.miui.home`（桌面），重启桌面生效。

## 说明

数据默认只在本机；如果在设置页填了局域网同步服务，计数、肌肉重量和体脂记录会同步到你自己树莓派上的服务（`/api/v1/sync`），用于多台手机和 Windows 数据中台查看。没有云端账号，不经过第三方服务器，也不上传健康数据。
