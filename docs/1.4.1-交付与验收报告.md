## 一、先说结论

1. **电脑端三个页面都变成一屏装下**：总览、今天、趋势都没有右侧滚动条，不用往下拖就能看全。总览里原来单占一块的「五个项目」拆掉，内容并进了顶部那 5 张卡。
2. **底部被「刀切」的问题没有了**：趋势页「这30天的节奏」下面现在有空白，和窗口底边不再贴着；上面和图表之间也恢复成正常的 24px 间距。
3. **切指标不再整页闪**：点「引体向上」「蹲马步」这些页签，只重画图表那一块，页面别的部分不动、位置也不跳。
4. **「停留几秒自己抖一下」的原因找到了也修了**：程序每 20 秒会去树莓派取一次数，以前不管有没有新数据都整页重画一遍、还重播入场动画。现在先比对数据，没变就什么都不做。七个页面同一套逻辑，不只项目页。
5. **所有弹窗都能点外面关掉**：连接树莓派、项目详情、项目编辑，以及以后新加的弹窗，在灰色遮罩上单击就关；`Esc` 也能关。
6. **手机 OKOK 首页该清的都清了**：热量记录卡、喇叭动画和滚动文字、书本图标、「每日签到送好礼」、「优惠购」页签、「卡片管理」以下全部内容（含「查看更多」和推荐卡片、「大家都在看」）。截图里首页只剩体重卡 + 目标 / 体重趋势 / 喝水 / 四宫格，底栏是首页 / 发现 / ＋ / 我的。
7. **没动的**：桌面「肌肉重量」大卡的位置留给你自己摆；树莓派服务端没改；计数方块、体脂大卡、OKOK 称重回传链路一律没碰。

## 二、电脑端：你提的每一条，现在是什么样

### 1. 总览：五个项目不再单占一块

- 原来的「五个项目」面板整块去掉了，你的图 1 里那 5 张卡不再出现。
- 它们的信息按「一卡一项目」并进了你图 2 红框里的那排指标卡：
  - 卡名 + 「每组 N 个 / 每组 N 分钟」
  - 右上角小环形：目标完成度百分比
  - 中间大数字：**今天**的值
  - 下面一行：`今天 N 组 · 昨天 X`
  - 再下面：近 14 天迷你折线（哪几天有记录一眼能看出来）
  - 最底：`累计 X 个 / 目标 Y`
- 顶部只留一行小标题：左边「五个项目 · 今天」，右边一个「打开项目页」的链接。
- 默认选中「肌肉重量」，和第一张卡保持一致——以前打开是俯卧撑，要自己点一下。
- 整页一屏：1456×802 的窗口里实测外层滚动为 0，最下面一排卡片和内容区底边还留了 4px。

### 2. 今天：删两块，剩下的重新分

- 删掉了顶部 5 张统计卡（你图 6 那排，含「数据来源 · 树莓派」那张）。
- 删掉了整块「今日趣事」。
- 腾出来的地方这么用：
  - 左边「今天，五个刻度」——五行按可用高度均分，正好铺满整张卡，不会上半截有、下半截空。
  - 右上「今天的数据」——2×2 四格：今日已记录 3/5、连续记录 3 天、今日组数 2 组、今天 11 月 26 日 周四。
  - 右下「今天的小结」——3 条（3 个项目有记录 / 2 组动作 / 连续 3 天），三条均分撑到卡片底部。
- 整页一屏，没有右侧滚动条；左卡和右卡底边平齐。

### 3. 趋势：底部留白、方框填满、能滚

- **底部被切**：原因不是卡片被裁，而是图表和统计卡原来各写死了一个最大高度（520 + 224），在真实窗口里两个加起来比可用高度多，最后一张卡就被推到窗口外面。现在改成按剩余空间自动分配，页面底部再留 14px 空白。实测「这30天的节奏」下沿 742，窗口内容底 756。
- **右侧「最近 14 天，逐日看」**：表格撑满整个方框，14 行一直铺到底部；方框里可以用滚轮往上翻更早的记录，滚动条仍然隐藏，滚到底不会带着整页一起动（实测滚轮三次，方框内滚了 213px，整页 `scrollY` 还是 0）。
- **切指标**：只重画「图表 / 统计 / 逐日」三块，页面骨架和位置都不动。

### 4. 全页面「抖一下」

- 大白话：程序后台每 20 秒去树莓派问一次「有没有新数据」，以前问完不管有没有变化，都把整个页面重新画一遍，还重播一次「从下往上淡入」的动画。你手没动，页面就自己抖了一下。
- 现在：先算一个「数据指纹」（版本号、修订号、各指标数值、体脂记录、备注、当前页面）。指纹没变就什么都不做；真变了才重画，而且重画不播动画。
- 实测：停在趋势页停留 24 秒，跨过一次 20 秒轮询，页面里的节点还是同一个（说明确实没重画）。
- 这套逻辑不在项目页一个地方，总览、今天、趋势、体脂率、项目、趣事、数据管理七个页面共用。

### 5. 弹窗点外面就关

- 所有弹窗共用一个组件，所以只改一处就全覆盖：在卡片外的灰色遮罩上单击即可关闭。
- 加了一个小保护：必须「按下」和「抬起」都在遮罩上才算，避免在卡片里按住、拖到外面松手时被误关。
- `Esc` 也能关。
- 实测：设置弹窗、项目详情弹窗点外部都能关，点卡片内部不会关。

## 三、手机：OKOK 首页清掉了哪些

| 清掉的 | 是什么 |
| --- | --- |
| 热量记录卡 | 首页中间那张带环形和「去记录」的卡 |
| 喇叭动画 + 滚动文字 | 热量记录卡上方那条会动的小喇叭和它右边轮播的文字 |
| 书本图标 | 热量记录卡右上角那个 |
| 每日签到送好礼 | 首页那个文字入口 |
| 优惠购 | 底部页签，整格摘掉，不留空槽（现在底栏是 首页 / 发现 / ＋ / 我的） |
| 卡片管理及以下全部 | 包括「查看更多」和它下面那排推荐卡片、「大家都在看」 |

做法上有两点要注意的：

- 先按文案判断（含「签到」和「好礼」，或以「大家都在看」开头），再按资源名判断，换文案也不至于漏。
- 隐藏之后把空的父容器一并收起来，否则页面底部会留一块白。
- 「发现」页单独 `dump` 过一遍，确认这些规则不会误伤它。

**没动的**：桌面「肌肉重量」大卡的位置按你说的留给你自己摆；计数方块、体脂大卡、OKOK 称重回传链路都没改。

## 五、已知边界

- **发布包不带任何真实地址和口令**：之前为了这台电脑免填，桌面端源码里写死了树莓派地址和口令，仓库一公开等于把口令发出去。1.4.1 已改成空默认，第一次打开手动填一次，只存在本机 `config.json`；本机已有配置的照旧自动连上。**注意：旧口令已经出现在一次公开提交的历史里，虽然只能在家里局域网用得到，仍建议换一串；要换的话我可以把树莓派、这台电脑、手机三处一起改（约 10 分钟）。**
- 手机端只支持 OKOK 3.7.63 / 255。OKOK 升级后清理规则会安全退出（不清、也不误删），到时需要重新对一遍控件。
- 极端矮的窗口（内容区低于 700px）趋势页统计卡会贴到内容区下沿，仍在窗口内；正常最大化窗口不受影响。
- 手机测试期间为了不让屏幕熄灭，临时把「保持唤醒」打开了，收尾已改回原设置。
