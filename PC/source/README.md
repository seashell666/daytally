# 日刻 · 数据中台（Windows 客户端）

一个连接树莓派 Docker 里「日刻」同步服务的 Windows 桌面客户端。界面沿用手机 App 的暖紫、米白、一点红的配色和圆角卡片，不另做一套后台管理系统。

## 直接使用

双击：

`dist\日刻数据中台.exe`

第一次打开会弹出「连接树莓派」：

- 树莓派 IP：自己家的局域网地址（例如 `192.168.1.50`）
- 端口：`8787`
- 访问口令（Token）：填手机 App「设置 → 同步服务」里那串 Token（就是树莓派 `server/.env` 的 `DAYTALLY_TOKEN`）

保存后会读到今天、近 30 天趋势、趣事、肌肉重量和四个计数项目，以及独立的体脂率记录。窗口会尽量最大化，适合在电脑上扫一眼。

## 包含什么

- **总览**：肌肉重量大卡、四个计数项目、最近 30 天折线图、今日趣事、项目预览。
- **今天**：肌肉重量和四个计数项目今天的数值、组数、最近 7 天小柱、和昨天的变化。
- **趋势**：按项目切换，30 天折线、最高/合计/有记录天数、最近 14 天逐日表；肌肉重量按公斤显示。
- **体脂率**：只读树莓派里的真实体脂记录。当前体脂率、最近一次测量时间/来源、历史最高最低、7 天/30 天/全部历史切换、逐点趋势图和历史明细；不混进肌肉重量，也不生成模拟历史。
- **项目**：肌肉重量加四个计数项目。单击看详情，双击编辑计数项目内容（名称、单位、每组数量、目标、纵轴上限）。肌肉重量是记录值，不按计数项目编辑；旧身高历史不再展示，也不参与趋势。
- **趣事**：自动从数据里生成「今天比昨天、最近峰值、连续记录」；也可以手写一条，存在这台 Windows 电脑上。
- **数据管理**：最醒目的「清空所有数据」，点击后必须先勾选确认，才会执行。会一起清掉体脂率记录。

## 清空数据的边界

点击「清空所有数据」后会清掉：

- 今天的计数和肌肉重量记录
- 所有历史计数和肌肉重量记录
- 所有体脂率记录
- 本机手写的趣事
- 手机端下次同步时也会看到归零

会保留：

- 五个项目（肌肉重量 + 四个计数）的名称
- 每组数量
- 单位
- 目标
- 纵轴上限

当前树莓派上的 1.4.0 服务有物理删除接口，客户端会调用 `/api/v1/admin/clear-data`，真正删除事件表、归零记录表和体脂记录表；项目配置原样保留。

如果树莓派仍是旧版服务端，客户端会自动退回 5 条「归零」指令：界面归零，但旧数据仍留在树莓派的数据库里。

## 开发 / 重新打包

所有 Windows 编译环境、依赖和构建工具都固定在：

`C:\windows软件编译`

本项目的构建用 Python 在：

`C:\windows软件编译\venv\Scripts\python.exe`

直接运行（开发调试）：

```powershell
& "C:\windows软件编译\venv\Scripts\python.exe" "C:\windows软件编译\daytally-dashboard\app.py"
```

只启动本地页面服务（方便浏览器截图/调试）：

```powershell
& "C:\windows软件编译\venv\Scripts\python.exe" "C:\windows软件编译\daytally-dashboard\app.py" --serve-only --port 8765
```

重新打包单文件 EXE：

```powershell
& "C:\windows软件编译\daytally-dashboard\build.ps1"
```

构建脚本会调用 `C:\windows软件编译\venv` 里的 PyInstaller，不会把依赖装到别处。

## 文件说明

- `app.py`：本地 HTTP 服务 + 树莓派请求转发 + pywebview 窗口
- `web/`：界面 HTML/CSS/JS 和图标
- `build.ps1`：打包脚本
- `tools/make_icon.py`：从 PNG 生成 Windows `.ico`
- `dist/日刻数据中台.exe`：可直接双击的单文件客户端

## 本机保存的位置

- 配置（地址、Token、趣事）：`%APPDATA%\DayTallyDesktop\config.json`
- 最近一次快照缓存：`%APPDATA%\DayTallyDesktop\snapshot-cache.json`
- 运行日志：`%APPDATA%\DayTallyDesktop\desktop.log`

Token 只保存在本机配置里，HTML 页面通过本地服务转发请求，不把 Token 写进网页。

## 已知边界

- 树莓派服务必须和这台 Windows 电脑在同一局域网，且 Docker 的 8787 端口可访问。
- 如果 Token 填错，界面会显示「连接异常」，数据区保留上一次读到的内容；改对后点刷新即可。
- 「趣事」的手写内容不写进树莓派数据库，只在这台 Windows 电脑上。
- 肌肉重量是单值记录，不做每组/目标/纵轴编辑；体脂率页也只读树莓派记录，不在电脑上新增或修改测量。
- 旧身高（`height`）只作为服务端兼容字段保留，不在 PC 页面展示，也不会把旧厘米数当成公斤显示。
